## Workflow
1.) think through ​the problem, read the code base and write a plan in todo.md file. 
2.) The plan should be a checklist ​of todo items
3.) Before executing the plan, ask me to verify ​the plan. 
4.) Complete the todo items one by one, and mark them off as you go.
5.) At every step, explain what you did. 
6.) Keep the change simple and miminal, and avoid big rewrite.
7.) At the end add a review ​section in todo.md file summarizing the changes.
8.) Go through the code you just wrote and ​confirm it follows security best practices. ​Check that no sensitive data is left in the front end and that ​there are no vulnerabilities an attacker could exploit.
9.) Please explain the functionality ​and the code you just built in detail. Walk me through what you changed and how ​it works. Act like you're a senior engineer ​teaching me.
